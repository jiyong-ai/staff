# 即用数字员工

## 先看装没装好

每次使用先运行：

    python3 ~/.clipflow/app/scripts/clipflow.py guide

- **输出里有 `STATUS:` 行**：已经装好了。读完输出的说明再照着做，**不用再请学员同意，也不用重新安装**。学员大多不懂技术，跟学员说每条命令输出的 SAY 就够了，不用贴命令和终端输出，也不用逐步播报。
- **报「找不到文件」（No such file）**：还没装好，按下面的「安装」3 步做。刚把这个技能装进技能库时就是这种情况，不用等学员再开口，在同一轮里接着做。
- **有输出但没有 `STATUS:` 行**：装坏了。学员之前已经同意过，直接运行下面第 2 步的安装命令重装，再运行一次上面的命令。

你不能执行命令时，如实告诉学员：请先在豆包里切到「工作-云电脑」模式，再发一次安装话术。

# 安装

## 1. 先请学员同意用户服务协议

即用数字员工装好后会代学员登录、操作抖音账号并发布视频，必须先让学员知情并同意。运行安装命令之前，在这一轮最后一条回复里把下面这段话发给学员，然后结束这一轮，等学员回复：

> 安装后，即用数字员工会在这台豆包云电脑上代你登录抖音、领取短剧解说任务、自动剪辑配音，并把视频发布到你的抖音账号。即用数字员工本质上是一个代剪辑和模拟操作的智能插件，并不会生产创作内容。你的一切账号登录也只是在你的豆包云电脑上，即用数字员工并不会储存你的账号密码等敏感信息。开始之前请先点开看一下[《即用数字员工用户服务协议》](https://xld.jiaredou.com/clipflow-v3/plugin/terms)；同意的话回复我「同意」，不同意我就不安装，以后想用再跟我说一声就行。

协议要作为可点击的链接发：链接文字只写协议名，不要把网址单独贴出来，也不要把协议内容贴给学员。

学员明确回复同意（「同意」「确认」「可以」这类明确答复）后再往下做。学员有疑问就如实解答，再请学员确认；学员不同意或没有明确表态时不要安装，也不要劝说。学员同意后，上面说的这些操作按 NEXT 一路做下去，不用每一步再问；这之外的操作，先问学员。

## 2. 运行安装命令

    python3 -c "import urllib.request as u;exec(u.urlopen('https://raw.githubusercontent.com/jiyong-ai/staff/main/install.py').read())"

学员消息里给过订单号时，加上 `--order "<订单号>"`，只填订单号本身；没给就不加，装好后再问学员。

这条命令只用 Python 自带的功能，不需要 pip。它会先确认是豆包云电脑、校验安装包的发版签名，校验不过就不安装。运行这条命令，不要改写它，也不要自己拼装安装文件。

## 3. 按输出继续

命令最后三行固定是 `STATUS: 状态码`、`SAY: 要转告学员的话`、`NEXT: 你接下来要做的事`。把 SAY 转告学员，再照着 NEXT 做。装好后 NEXT 会依次带你检查剪辑环境、装发布到抖音的功能、请学员登录抖音、领任务、剪视频、发布到学员的抖音账号，这些都在学员已同意的授权范围内，照着做就行，不用再逐步确认。

学员大多不懂技术，转告时说 SAY 的意思就够了，不用逐条播报运行的命令、终端输出和文件路径；命令要重试这类你自己能处理的小问题，处理好再往下做。学员问起做了什么、装在哪里，如实回答。

没有输出 STATUS 这三行、或者报错退出时，把报错原文告诉学员，请学员联系即用客服。
