# 即用数字员工 · 安装

这是「即用数字员工」（短剧解说剪辑，豆包云电脑专用）的官方安装地址，供已购课学员使用。

## 怎么安装

1. 在豆包云电脑里打开豆包，**先切到「工作-云电脑」模式**（普通聊天模式装不了）。
2. 把下面这句话发给它：

```
豆包你好，帮我安装Github上 jiyong-ai/staff 到技能库里
```

豆包把技能放进技能库后，会告诉你已经装好。

3. 想开始时对它说「开始」。第一次使用时它会先请你看一下用户服务协议，你回复「同意」后完成安装，再问你要抖音订单号。之后说「领任务」就行，即用数字员工会自动保持最新版本，不用重新安装。

## 用 npx skills add 安装

熟悉命令行的话，也可以在豆包云电脑的终端里运行（需要 Node.js 22.20 或更新的版本）：

```sh
npx skills add jiyong-ai/staff -g -a universal -y
```

装好后新开一个豆包对话，说「开始」。即用数字员工只能在豆包云电脑上用，其他电脑上装了也运行不了。

## 常见问题

- **助手说它不能执行命令，或者说这里装不了**：即用数字员工只能在豆包云电脑上用，请在豆包云电脑里打开豆包、切到「工作-云电脑」模式，再发一次上面那句话。
- **提示订单号无效**：核对订单号是否抄错；确认无误仍然不行，请联系即用客服。
- **安装报错**：把报错原文发给即用客服。不要自己修改安装命令或文件。
